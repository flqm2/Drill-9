# 소년 이동 실습 실행 안내

## 실행

Python과 pico2d가 설치된 환경에서 프로젝트 루트를 기준으로 실행한다.

```powershell
python Script/drill-09_character_move.py
```

리소스 위치는 소스 파일을 기준으로 계산하므로 다른 작업 폴더에서 절대 경로로 실행해도 된다. `Script`와 `Resourse`의 상대적인 폴더 구조는 유지한다.

## 조작과 동작

- 방향키를 누르고 있는 동안 이동하며, 놓으면 해당 방향의 이동을 중단한다.
- 좌우 입력으로 바라보는 방향을 바꾼다. 위·아래 이동에서는 직전 좌우 방향을 유지한다.
- 대각선 이동 속도는 단일 방향 이동 속도와 같다. 반대 방향 입력은 해당 축에서 상쇄한다.
- 캐릭터 전체가 화면 경계를 벗어나지 않는다.
- 이동 입력이 없으면 IDLE 상태로 전환하여 방향에 맞는 1·2행의 정지 애니메이션을 순환한다. 이동 시에는 방향에 맞는 3·4행의 달리기 애니메이션을 사용한다.
- 창을 닫으면 종료한다. 다른 창으로 전환하면 눌린 방향키 기록을 해제한다.

화면은 1280×1024, 캐릭터 표시 크기는 100×100이다. 이동 속도는 초당 250픽셀이며, 프레임 간격은 이동 시 0.10초, 정지 시 0.20초이다. 소스 상단의 상수에서 조정할 수 있다.

## 검증

```powershell
python -m unittest discover -s Script -p test_drill09.py -v
```

자동 검증 11개가 통과했다. 네 방향 이동, 경과 시간에 따른 이동 거리, 대각선 속도, 방향 유지, 네 모서리 제한 및 복귀, IDLE 애니메이션, 전환 시 프레임 초기화, 키 해제, 포커스 해제, 스프라이트 행 선택, 종료 처리를 확인한다.

SDL의 창을 표시하지 않는 환경에서 실제 배경과 스프라이트를 로딩하고 IDLE·MOVE의 좌우 방향에 해당하는 네 행 전체의 32프레임 렌더링도 확인했다. 실제 창에서 키보드를 직접 조작하는 수동 검수는 별도로 진행해야 한다.

개발 기능은 한글 메시지를 사용한 20개의 단계별 커밋으로 기록했다. 검증 코드와 이 안내 문서는 후속 커밋에 포함한다.
